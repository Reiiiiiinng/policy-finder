## V1.0 完成功能

项目定位：

不是：
- 政策搜索工具
- 政策问答机器人
- ChatGPT 套壳
- AI 审批系统

核心定位：

帮助家庭从生活变化中发现可能遗漏的公共服务权益。

AI 负责：

- 理解用户生活场景
- 召回可能相关政策
- 解释推荐原因
- 展示政策证据
- 提示待确认条件
- 提供官方办理渠道

不负责：

- 判断用户最终资格
- 自动申请
- 保证领取
