# 《政策找人》V3.4｜本地验收

在作品源代码根目录运行。本地预览只监听回环地址。建议使用 Python 3.12 或更新版本和 Microsoft Edge。静态截图可直接打开。

模拟演示使用固定合成数据与标记过的模拟 AI／搜索；它不需要外部账号。以下 PowerShell 命令仅在名为 `contest-review` 的验收实例不存在时建立新库：

```powershell
$env:PF_V33_PORT = "8147"
$env:PF_V33_INSTANCE = "contest-review"
$env:PF_V33_SEARCH_MODE = "mock"
$env:PF_V34_CARE_FIXTURE = "1"
python -c "import sys; from pathlib import Path; sys.path.insert(0,'backend'); import followup_db as d; p=Path('data/private-migration/v33-contest-review/acceptance.db'); p.parent.mkdir(parents=True, exist_ok=True); assert not p.exists(), 'Instance already exists'; d.initialize(p)"
python tests/preview_trip.py
```

打开 [http://127.0.0.1:8147/](http://127.0.0.1:8147/)，选合成家庭成员。养老案例：佛山市，68 岁，长期卧床，需要上门照护，未做能力评估。重启时复用此前专用验收库：只执行设置同样环境变量和启动服务的命令。

需要真实 DeepSeek 时，由运行方在本机给服务进程设置 `DEEPSEEK_API_KEY` 后运行 `python preview.py`；需要真实 CleverSee 时，同时设置 `PF_V33_SEARCH_MODE=live`、`CLEVERSEE_ENABLED=1` 和 `CLEVERSEE_API_KEY`。密钥和运行生成的数据库不得加入材料。公开演示通过录制视频，不开放验收服务到公网。
