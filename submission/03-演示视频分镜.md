# 演示视频分镜｜建议约 3 分钟

时长与分镜是录制建议，实际上传规格由表单和赛道通知决定。只录合成案例画面。把真实 AI、模拟回归和本人记录三者标清。

| 时间 | 画面和操作 | 旁白要点 |
| --- | --- | --- |
| 0:00–0:18 | 首页，顺着底部导航点击「AI发现」 | 长辈照护需求变化，但政策条文难找、窗口难选。我们从家庭的实际处境出发。 |
| 0:18–0:45 | 选合成家庭成员；填佛山、68岁和卧床、洗澡穿衣需协助、未做正式能力评估 | 示例是合成家庭。DeepSeek 帮忙识别需求，资格仍需要正式评估。等待可剪短，保留真实操作结果。 |
| 0:45–1:12 | 展开养老服务消费补贴卡；展示官方原文、待核实条件；选权益，集中核对 | 可看到为什么相关、政策出处，以及还应该核对什么。公共权益推荐不会混入商业保险。 |
| 1:12–1:47 | 进入少跑腿计划，补充条件、查看材料，再查看官方渠道「民政通」 | 先在民政通查养老服务消费补贴和评估指引。有缺口时先找对办理方，避免白跑一趟。 |
| 1:47–2:15 | 打开待核实咨询，回到同一事项 | 把待问问题整理好，咨询记录只记录用户得到的信息，不等于官方认定。 |
| 2:15–2:45 | 可切换至模拟验收实例，录已提交／需补件；随后从「我的」回到保存的计划 | 进度演示使用模拟办理；点击准备提交本身不会写入已提交。计划可恢复。 |
| 2:45–3:00 | 回到权益卡和页面总览，出作品名 | 让家庭查得到依据、看得懂下一步、办完能回看。 |

建议录制使用 390px 逻辑宽度，隐藏调试工具与私人浏览器资料。正式录制前确认真实服务状态，发生服务故障时可换模拟版本并保留明确标识。导出后检查字幕、手机画面可读性、外部链接和无线网络下的可访问性。发布至 B站、抖音等公开视频平台，匿名/无痕打开验证播放，再复制直接视频地址；不要填云盘视频链接。
