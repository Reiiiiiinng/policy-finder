# 政策找人｜V3.4

2026 年第九届传智杯 AIGC 多维设计创新挑战赛 · 绿智共生 · UI 交互设计

给家人找政策时，困难往往是从生活情况走到下一步：这项政策为什么和我有关、哪里待核实、要准备什么、去哪问。《政策找人》让用户为指定家庭成员描述情况，从有出处的公共服务目录发现可能相关的权益，再把选中的事项整理成可以继续办理的少跑腿计划。

| 功能 | 用户得到什么 |
| --- | --- |
| AI 发现 | 用日常语言描述近况；查看公共权益、推荐理由、原文和仍需核实的条件 |
| 集中核对 | 只处理选中的事项，复用已有信息；把个人陈述、规则匹配和官方核定分开 |
| 少跑腿计划 | 了解下一步、准备材料、查看正规渠道、整理咨询问题；从咨询返回原事项，从「我的」继续 |
| 进度记录 | 由用户分别记录准备、实际提交和后续反馈；记录属于个人办理日志 |
| 查政策 | 本地证据目录与联网搜索分开，官方原文、待核线索和第三方资讯分别展示 |

暖米白界面、森林绿主色、五栏导航和 2px 绿边推荐卡贯穿流程。设计围绕「能做什么、还差什么、下一步去哪」组织页面。通过出门前核对和电子材料准备减少不必要的往返；未测量实际出行减少量或碳减排量。

技术：HTML/CSS/JavaScript 前端 → Python API → 地区政策 JSON、规则匹配与 SQLite 持久化。DeepSeek 从家庭描述提取信息并在后端允许的目录候选内排序；页面政策信息和办理细节来自目录。CleverSee 用于公共政策联网搜索，搜索命中不自动转为可办理依据。

演示使用合成家庭。页面展示和平台记录均不能作为官方受理、资格认定或补贴发放证明。
