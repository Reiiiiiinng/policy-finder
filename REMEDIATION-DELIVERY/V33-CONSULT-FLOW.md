# V3.3 咨询联动

- 从条件条目进入咨询时带上 plan、member、pid、query、task、region 及 condition。自行填写的客观条件无需咨询按钮。咨询页面验证任务和地区与载入计划相符。
- 咨询内容由其任务实时 conditionChecks 生成。已知符合、已明确不符合以及非主条件的重复提示被排除。当前条件优先显示。复制包含政策、城市、简短家庭背景、问题和希望确认的受理事项。
- 条件页返回打开原条目并滚动到它。办理渠道页返回到官方渠道区域。刷新可按 URL 重建目标。「未咨询」直接返回无写入。轻量联系标记保存在任务要求里，答复转记沿用现有 consultations 记录及来源字段，资格和材料均独立。
- 粤府办〔2022〕3号在政府页面标为现行有效。第四、十六条可区分政策发布机关、民政审核和镇街受理。区街电话、线上入口及两项佛山本地旧链接仍待当地正式来源支持，本轮保留待核实提示。[广东省人民政府办公厅原文](https://www.gd.gov.cn/gkmlpt/content/3/3834/mpost_3834468.html)
