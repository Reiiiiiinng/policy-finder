## 已实施

- **恢复链路。** 对照审计 UUID，确认上轮写入落入两份历史库。隔离服务现要求显式预备 SQLite，固定连接路径，新增进程锁和实例响应校验。历史库只读核验，本轮前后摘要一致。
- **咨询。** 按条件直达，使用任务实时待核实数据，复制可使用的咨询内容，返回原子页和条目。支持自愿联系标记与答复转记，独立于资格、材料和实际提交。
- **办理。** 增加待提交、反馈和办结区分、首次提交和补交记录、终态更正、整计划暂停恢复，以及未通过后的同成员替代建议和空结果。
- **草稿。** 服务端按成员与查询 ID 保存，发布查询后只清理同 ID 草稿。保存失败保留本页输入并有可见提示。
- **真实 AI。** 原配置 DeepSeek 连通、分析、追问和确认新事实后的再研判已经验证。真实联网搜索被现有关闭开关阻断。
