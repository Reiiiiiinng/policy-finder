# V3.3 办理状态与事件

| 动作 | 阶段与来源 |
|---|---|
| 明确保存提交前核对 | 待提交。写核对快照，提交为空，仍可改材料。 |
| 明确记录实际提交 | 办理中、等待反馈。保存用户自述日期、渠道和回执。 |
| 记录已收到反馈 | 仍为办理中，页面提示已收到官方反馈，来源标明用户自行记录、尚未独立核实。 |
| 记录需补件、确认补交 | 需补件 → 办理中。保留首次提交，单独记录最近补交。所有提交和结果存事件。显示旧数据时可从历史事件恢复首次提交。 |
| 记录办结或未通过 | 两个独立终态。未通过从原成员、地区查询的当前目录结果中检索，按原因关键词优先排列，显示不确定项或暂无匹配。 |
| 更正终态 | 平台显示原状态，输入原因并确认后重新开放事项。更正事件记录原结果、原因、时间。 |
| 暂停单项 | 仅该任务暂停，可回原阶段。 |
| 暂停整计划 | 单独保存计划暂停时间和原因，保留每项状态与材料。暂停时可以查看，恢复后再更新。 |

此产品记录用户操作和用户转记。政府文书正文、条件依据和用户报告各有来源，可验证的结果文书接入仍待业务来源支持。
