## 合成场景

| 场景 | 覆盖结果 |
| --- | --- |
| A 佛山居家养老 | 模拟 AI 提取与目录推荐进入养老服务消费补贴；需要官方能力评估；推荐、集中核对与计划投影保留民政通和来源。 |
| B 医疗救助 | 已知参保复用；未参加医保也保留医疗救助；定点机构的一站式结算可在政策渠道查看。 |
| C 临时救助 | 突发生活困难、窗口出处、区级联系目录和核对、计划链路通过。 |
| D 信息不足 | 未知年龄和医保仍可保存与规划，下一步展示待核实事实。 |
| E 明确不符 | 明确未参保时，旧大病保险候选规则筛除；集中核对发现就医机构不符时标记相关单项冲突。 |
| F 失效或替代 | 合成失效和被替代快照均被当前推荐排除，已有计划保留历史可追溯性。 |
| G 具体渠道未核实 | 用无直接地址、电话及具体办理入口的事项验证；渠道保持可追溯来源，并可继续进入计划咨询。 |

A–G 中的事实提取与研判使用合成模型或规则，场景覆盖见 `tests/test_v32.py`。A–G 的组合边界自动化与 Edge 全链路回归是两套测试。
